# Тесты

Проект использует `pytest`. 

## Запуск
Из корня проекта: `.\run_test.bat` (Windows) или `pytest tests/` (Linux/Mac).

## Структура
- `unit/` — быстрые тесты (парсер, скрипты, БД).
- `api/` — тесты эндпоинтов (FastAPI TestClient).
