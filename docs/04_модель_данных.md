# Модель данных

Версия: 0.2 (часть 1: справочники)
Статус: Черновик
Последнее обновление: 2026-10-22

Документ описывает структуру базы данных: таблицы, поля, типы, ограничения, связи. Разбит на части:
1. Справочники (этот раздел)
2. Товары и склад
3. Закупка
4. Продажа
5. Покупатели и поставщики

---

## Общие соглашения

- **Имена таблиц** — в camelCase, множественное число: `genres`, `platforms`, `purchaseOrders`.
- **Имена полей** — в camelCase: `genreId`, `avgCostRub`, `createdAt`.
- **Первичные ключи** — `<tableNameSingular>Id`: `genreId`, `platformId`, `orderId`.
- **Внешние ключи** — `<referencedTableSingular>Id`: `genreId` в `productGenres` ссылается на `genres.genreId`.
- **Деньги** — `NUMERIC(12,2)` для сумм, `NUMERIC(14,4)` для курсов валют.
- **Даты** — `DATE` для дат без времени, `TIMESTAMP` для дат со временем.
- **Аудит** — `createdAt TIMESTAMP NOT NULL DEFAULT NOW()`, `updatedAt TIMESTAMP`.
- **Справочники** — всегда имеют `sortOrder SMALLINT NOT NULL DEFAULT 100` и `isActive BOOLEAN NOT NULL DEFAULT TRUE`.
- **Ссылочная целостность** — все FK с явными `ON DELETE` / `ON UPDATE` политиками.

## 1. Справочники

### 1.1. `countries` — Страны

**Назначение:** справочник стран по ISO 3166-1. Заполняется из готового дампа (репозиторий `stefangabos/world_countries` или аналог).

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `countryId` | `SMALLSERIAL` | `PRIMARY KEY` | автоинкремент | Уникальный идентификатор |
| `isoAlpha2` | `CHAR(2)` | `NOT NULL`, `UNIQUE` | — | Код страны по ISO 3166-1 alpha-2 (RU, US, JP) |
| `isoAlpha3` | `CHAR(3)` | `UNIQUE` | — | Код по ISO 3166-1 alpha-3 (RUS, USA, JPN) |
| `countryName` | `VARCHAR(100)` | `NOT NULL` | — | Название страны (на английском) |
| `countryNameRu` | `VARCHAR(100)` | | — | Название страны на русском |
| `isActive` | `BOOLEAN` | `NOT NULL` | `TRUE` | Признак «страна используется» |

**Индексы:**
- `PRIMARY KEY (countryId)`
- `UNIQUE (isoAlpha2)`, `UNIQUE (isoAlpha3)`

**Источник данных:** готовый SQL-дамп по ISO 3166-1 (не заполняем вручную). **Важно:** для интерфейса и аналитики обычно достаточно хранить название на одном языке и переводить его в интерфейсе. Поле `countryNameRu` — **опционально**; его можно добавить позже, если понадобится. На MVP достаточно `countryName`.

### 1.2. `regions` — Регионы выпуска

**Назначение:** регион выпуска/распространения товара. Примеры: `US`, `EU`, `RU`, `Asia`, `JP`, `China`, `Australia`, `South America`.

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `regionId` | `SMALLSERIAL` | `PRIMARY KEY` | автоинкремент | Уникальный идентификатор |
| `regionCode` | `VARCHAR(10)` | `NOT NULL`, `UNIQUE` | — | Краткий код (US, EU, RU, Asia, JP, CN, AUS, SA) |
| `regionName` | `VARCHAR(50)` | `NOT NULL` | — | Полное название (United States, Europe, ...) |
| `sortOrder` | `SMALLINT` | `NOT NULL` | `100` | Порядок вывода |
| `isActive` | `BOOLEAN` | `NOT NULL` | `TRUE` | Признак «регион используется» |

**Индексы:**
- `PRIMARY KEY (regionId)`
- `UNIQUE (regionCode)`

**Стартовые данные:** US, EU, RU, Asia, JP, CN (China), AUS (Australia), SA (South America). При необходимости список можно расширить.

**Назначение:** игровые платформы с указанием версии/поколения. Включает **все возможные платформы** (в том числе ретро).

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `platformId` | `SMALLSERIAL` | `PRIMARY KEY` | автоинкремент | Уникальный идентификатор |
| `platformName` | `VARCHAR(50)` | `NOT NULL` | — | Название платформы (`PlayStation`, `Nintendo Switch`) |
| `platformVersion` | `VARCHAR(20)` | `NOT NULL` | — | Версия/поколение (`4`, `5`, `1`, `2`, `Mega Drive`, `NES`) |
| `sortOrder` | `SMALLINT` | `NOT NULL` | `100` | Порядок вывода |
| `isActive` | `BOOLEAN` | `NOT NULL` | `TRUE` | Признак «платформа используется» |

**Индексы:**
- `PRIMARY KEY (platformId)`
- `UNIQUE (platformName, platformVersion)` — одна и та же платформа+версия не дублируется

**Назначение:** справочник валют для заказов и склада. MVP: RUB, USD, EUR, JPY, GBP. Криптовалюты (BTC, USDT, ETH) — опционально, с `NULL` курсами на старте.

### 1.10. `statuses` — Статусы заказов

| `sortOrder` | `SMALLINT` | `NOT NULL` | `100` | Порядок вывода |
| `isActive` | `BOOLEAN` | `NOT NULL` | `TRUE` | Признак «статус используется» |

**Индексы:**
- `PRIMARY KEY (statusId)`
- `UNIQUE (statusName)`

**Стартовые данные:**

| statusName | statusType | sortOrder |
|---|---|---|
| `paid` | common | 10 |
| `collected` | common | 20 |
| `delivery` | common | 30 |
| `customs` | purchase | 40 |
| `received` | common | 50 |
| `on_warehouse` | purchase | 60 |

### 1.11. `exchangeRates` — Курсы валют

**Назначение:** история курсов валют на дату. Нужна для пересчёта себестоимости в три валюты склада и для аналитики.

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `exchangeRateId` | `SERIAL` | `PRIMARY KEY` | автоинкремент | Уникальный идентификатор |
| `rateDate` | `DATE` | `NOT NULL` | — | Дата курса |
| `currencyFromId` | `SMALLINT` | `NOT NULL`, `REFERENCES currencies(currencyId)` | — | Из валюты |
| `currencyToId` | `SMALLINT` | `NOT NULL`, `REFERENCES currencies(currencyId)` | — | В валюту |
| `rate` | `NUMERIC(14,4)` | `NOT NULL`, `CHECK (> 0)` | — | Курс |
| `source` | `VARCHAR(50)` | `NOT NULL` | `'CBR'` | Источник (`CBR`, `manual`) |
| `createdAt` | `TIMESTAMP` | `NOT NULL` | `NOW()` | Когда запись создана |

**Индексы:**
- `PRIMARY KEY (exchangeRateId)`
- `UNIQUE (rateDate, currencyFromId, currencyToId)` — один курс на дату/пару
- `INDEX (rateDate)` — для быстрого поиска курса на дату

**Логика:** храним курсы `USD→RUB`, `EUR→RUB`, `JPY→RUB`, `GBP→RUB` из ЦБ РФ. Кросс-курсы считаем через RUB. Для криптовалют — ручное заполнение или внешний API (фаза 2).
