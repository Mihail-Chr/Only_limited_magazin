Первый документ серии «Модель данных». Здесь описаны справочники — медленно меняющиеся сущности, которые используются во всех контурах (закупка, продажа).

Серия:
1. `04_модель_данных.md` — справочники (этот документ)
2. `041_модель_данных.md` — товары и склад
3. `042_модель_данных.md` — закупка
4. `043_модель_данных.md` — продажа

---

## Общие соглашения

- **Имена таблиц** — camelCase, множественное число: `genres`, `platforms`, `purchaseOrders`.
- **Имена полей** — camelCase: `genreId`, `avgCostRub`, `createdAt`.
- **Первичные ключи** — `<tableNameSingular>Id`: `genreId`, `platformId`.
- **Внешние ключи** — `<referencedTableSingular>Id`.
- **Деньги** — `NUMERIC(12,2)` для сумм, `NUMERIC(14,4)` для курсов.
- **Даты** — `DATE` (без времени), `TIMESTAMP` (со временем).
- **Аудит** — `createdAt TIMESTAMP NOT NULL DEFAULT NOW()`, `updatedAt TIMESTAMP`.
- **Справочники** — всегда имеют `sortOrder SMALLINT NOT NULL DEFAULT 100` и `isActive BOOLEAN NOT NULL DEFAULT TRUE`.
- **Ссылочная целостность** — все FK с явными `ON DELETE` / `ON UPDATE`.

## 1. Справочники

### 1.1. `countries` — Страны

**Назначение:** справочник стран по ISO 3166-1. Заполняется из готового дампа (`stefangabos/world_countries`).

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `countryId` | `SMALLSERIAL` | `PRIMARY KEY` | автоинкремент | Уникальный идентификатор |
| `isoAlpha2` | `CHAR(2)` | `NOT NULL`, `UNIQUE` | — | Код ISO 3166-1 alpha-2 (RU, US, JP) |
| `isoAlpha3` | `CHAR(3)` | `UNIQUE` | — | Код ISO 3166-1 alpha-3 (RUS, USA, JPN) |
| `countryName` | `VARCHAR(100)` | `NOT NULL` | — | Название на английском |
| `countryNameRu` | `VARCHAR(100)` | `NOT NULL` | — | Название на русском |
| `isActive` | `BOOLEAN` | `NOT NULL` | `TRUE` | Признак «используется» |

**Индексы:** `PRIMARY KEY (countryId)`, `UNIQUE (isoAlpha2)`, `UNIQUE (isoAlpha3)`.

**Бизнес-правила:** `countryNameRu` — обязателен, заполняется при импорте дампа. Храним оба языка в БД (быстрее, чем перевод в интерфейсе).

### 1.10. `statuses` — Статусы заказов

**Назначение:** статусы заказов на закупку (посылки) и продажу. **Без `common`, без `shipment`** — только `purchase` и `sale`.

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `statusId` | `SMALLSERIAL` | `PRIMARY KEY` | автоинкремент | Уникальный идентификатор |
| `statusName` | `VARCHAR(30)` | `NOT NULL` | — | Название (`paid`, `shipped`, ...) |
| `statusType` | `VARCHAR(20)` | `NOT NULL`, `CHECK (IN ('purchase','sale'))` | — | Контур |
| `sortOrder` | `SMALLINT` | `NOT NULL` | `100` | Порядок вывода |
| `isActive` | `BOOLEAN` | `NOT NULL` | `TRUE` | Признак «используется» |

**Индексы:** `PRIMARY KEY (statusId)`, `UNIQUE (statusName, statusType)` — позволяет `shipped` дважды (purchase и sale).

**Стартовые данные:**

| `statusName` | `statusType` | `sortOrder` | Контекст |
|---|---|---|---|
| `at_carrier` | `purchase` | 10 | Посылка: поступила в СД (на СВХ) |
| `shipped` | `purchase` | 20 | Посылка: отправлена, трек присвоен |
| `customs` | `purchase` | 30 | Посылка: на таможне |
| `out_for_delivery` | `purchase` | 40 | Посылка: в доставке (опц.) |
| `received` | `purchase` | 50 | Посылка: получена |
| `paid` | `sale` | 60 | Заказ: оплачен |
| `shipped` | `sale` | 70 | Заказ: передан в доставку |
| `received` | `sale` | 80 | Заказ: получен покупателем |
| `refusal` | `sale` | 90 | Заказ: отказ / возврат |

`collected` — **убран** (избыточен).

### 1.15. `sellers` — Поставщики

**Назначение:** поставщики, у которых закупаем. Справочник.

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `sellerId` | `SMALLSERIAL` | `PRIMARY KEY` | автоинкремент | Уникальный идентификатор |
| `sellerName` | `VARCHAR(100)` | `NOT NULL` | — | Название (`Amazon JP`, `eBay private seller (US)`) |
| `purchasePlatformId` | `SMALLINT` | `NOT NULL`, `REFERENCES purchasePlatforms(purchasePlatformId)` | — | Площадка закупки |
| `marketplaceSellerId` | `VARCHAR(100)` | | — | Внутренний ID продавца на площадке (опц.) |
| `sellerType` | `VARCHAR(20)` | `NOT NULL`, `CHECK (IN ('shop','private','forwarder'))` | — | Тип: магазин / частный / посредник |
| `countryId` | `SMALLINT` | `REFERENCES countries(countryId)` | — | Страна регистрации (опц., не приоритет 1–2 года) |
| `contactEmail` | `VARCHAR(100)` | | — | Email (опц.) |
| `website` | `VARCHAR(200)` | | — | Сайт (опц.) |
| `notes` | `TEXT` | | — | Заметки. Опционально |
| `sortOrder` | `SMALLINT` | `NOT NULL` | `100` | Порядок вывода |
| `isActive` | `BOOLEAN` | `NOT NULL` | `TRUE` | Признак «используется» |
| `createdAt` | `TIMESTAMP` | `NOT NULL` | `NOW()` | Когда создан |
| `updatedAt` | `TIMESTAMP` | | — | Когда изменён |

**Индексы:**
- `PRIMARY KEY (sellerId)`
- `UNIQUE (purchasePlatformId, sellerName)` — уникальность в рамках площадки
- `UNIQUE (purchasePlatformId, marketplaceSellerId)` — если ID заполнен
- `INDEX (countryId)`

**Бизнес-правила:**
- `sellerName` уникален **в рамках площадки**.
- **Физлица группируем:** `sellerType = 'private'`, одна запись на площадку/регион (`eBay private seller (US)`). 40–50 записей вместо сотен. `marketplaceSellerId = NULL` для групп.
- `marketplaceSellerId` — для магазинов (если известен внутренний ID на eBay/Amazon).
- `countryId` — **опционально**. На 1–2 года не приоритет. Логистика важнее → `shipments.originCountryId`.
- Поставщика нельзя удалить, если есть заказы (`ON DELETE RESTRICT`). Для «удаления» — `isActive = FALSE`.
