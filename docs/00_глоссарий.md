# Глоссарий проекта

Версия: 0.1
Статус: Черновик
Последнее обновление: 2026-10-21

Здесь собраны ключевые термины, которые используются в проекте. Если термин не указан — значит, он ещё не согласован или не важен на текущем этапе.

---

| Термин | Определение |
|---|---|
| **Закупка (Purchase)** | Процесс приобретения товара у зарубежного поставщика. Включает оформление заказа, оплату, доставку и получение на склад. |
| **Продажа (Sale)** | Процесс реализации товара конечному покупателю через маркетплейс или другой канал. |
| **Заказ на закупку (Purchase Order)** | Документ, фиксирующий намерение купить определённые товары у поставщика. Содержит шапку (поставщик, дата, статус, валюта) и одну или несколько позиций. |
| **Заказ на продажу (Sales Order)** | Документ, фиксирующий факт продажи товаров покупателю. Содержит шапку (покупатель, маркетплейс, дата, статус) и одну или несколько позиций. |
| **Позиция заказа (Order Item)** | Строка в составе заказа, содержащая конкретный товар, его количество и цену за единицу (или общую стоимость). В одном заказе может быть несколько позиций с разным количеством. |
| **Товар (Good / Product)** | Любая единица ассортимента: игра, аксессуар, коллекционное издание, стилбук и т.д. |
| **Издание (Edition)** | Тип комплектации игры: Standard, Deluxe, Collector's, Limited, Steelbook, Signature и т.д. Хранится в отдельном справочнике `editionTypes`. |
| **Сборник (Bundle)** | Товар, содержащий несколько разных игр в одной упаковке (например, «Trine Ultimate Collection» или «The Banner Saga Trilogy»). Для аналитики связь между сборником и входящими в него играми описывается через M2M-таблицу `bundleItems`. |
| **Поставщик (Seller / Vendor)** | Юридическое или физическое лицо, у которого мы закупаем товар. |
| **Посылка (Shipment)**	| Физическая отправка товара от поставщика (или посредника) к нам. Одна посылка может содержать позиции из нескольких заказов на закупку. Имеет собственный трек-номер, стоимость доставки, сумму таможенной пошлины и статус.
| **Консолидированная посылка (Consolidated Shipment)** | Посылка, в которой объединены товары из нескольких заказов на закупку (обычно от разных поставщиков через посредника), чтобы снизить стоимость доставки.
| **Трек-номер (Track Number)** | Уникальный идентификатор посылки в службе доставки.
| **Таможенная пошлина (Customs Duty)** | Обязательный платёж при ввозе товара через границу. Начисляется на посылку в целом.
| **Стоимость доставки (Delivery Cost)** | Расходы на транспортировку посылки. Учитываются как часть себестоимости товара.
| **Себестоимость с учётом доставки и пошлин (Landed Cost)** | Полная стоимость единицы товара на складе: цена у поставщика + доля стоимости доставки + доля таможенной пошлины. Используется в формуле средневзвешенной себестоимости.
| **Покупатель (Buyer / Customer)** | Лицо, приобретающее товар у нас. Может быть как зарегистрированным, так и «гостевым» (без создания учётной записи). |
| **Маркетплейс (Marketplace)** | Площадка, через которую осуществляется продажа: OZON, Avito, VK, собственный сайт и т.д. |
| **Склад (Warehouse)** | Место хранения товара. Учитывает физическое количество, средневзвешенную себестоимость и количество единиц, находящихся в предпродажной подготовке (`countOfRepair`). |
| **Средневзвешенная себестоимость (Weighted Average Cost)** | Способ оценки запасов, при котором стоимость единицы товара пересчитывается при каждом поступлении по формуле: `(старое количество × старая средняя цена + новое количество × цена поступления) / (старое количество + новое количество)`. |
| **Предпродажная подготовка (Repair / Preparation)** | Состояние товара на складе, когда он уже получен, но ещё не готов к продаже (проверка, комплектация, устранение мелких дефектов). Учитывается в поле `countOfRepair` таблицы `warehouse`, а не как статус заказа. |
| **Статус заказа (Order Status)** | Текущее состояние заказа в жизненном цикле (например, `paid`, `collected`, `delivery`, `customs`, `received`, `on_warehouse`). Статус устанавливается на уровне заказа в целом. |
| **Регион (Region)** | Географический регион выпуска или распространения товара (US, EU, RU, Asia, JP и т.д.). Хранится в справочнике `regions`. |
| **Платформа (Platform)** | Игровая платформа с указанием версии: PlayStation 4, PlayStation 5, Nintendo Switch 1, Nintendo Switch 2, Sega Mega Drive и т.д. Хранится в справочнике `platforms`. |
| **Жанр (Genre)** | Категория игры: Action, Horror, Strategy, Adventure и т.д. Связь с товаром — многие-ко-многим через `productGenres`. |
| **Язык (Language)** | Язык интерфейса или субтитров игры. Связь с товаром — многие-ко-многим через `productLanguages`. |
| **Валюта (Currency)** | Денежная единица, используемая при закупке или продаже (RUR, USD, EUR и т.д.). |

## Принятые сокращения

| Сокращение | Расшифровка |
|---|---|
| M2M | Many-to-Many (связь «многие-ко-многим») |
| FK | Foreign Key (внешний ключ) |
| PK | Primary Key (первичный ключ) |
| MVP | Minimum Viable Product (минимально жизнеспособный продукт) |
