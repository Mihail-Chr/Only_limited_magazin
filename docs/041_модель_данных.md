### 1.7. `typeGoods` — Типы товаров (обновление)

**Стартовые данные:**

| Тип | Описание |
|---|---|
| game | Игра (физическая или цифровая) |
| bundle | Сборник игр (несколько игр в одной коробке). Состав — в `bundleItems` |
| steelbook | Стилбук (металлическая коробка) |
| gamepad | Геймпад |
| joystick | Джойстик |
| collectorBox | Коллекционная коробка |
| accessory | Аксессуар (общее) |
| card | Карточки (коллекционные) |
| toy | Игрушка |
| figure | Фигурка |
| badge | Значок |
| sticker | Наклейка |

*Примечание:* тип `bundle` заменяет флаг `isBundle`. Сборник определяется по `typeGoodId = 'bundle'`.
