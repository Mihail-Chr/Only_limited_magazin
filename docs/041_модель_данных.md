## 2. Товары и склад

### 2.1. `goods` — Товары

**Назначение:** карточка товара. Один SKU = одна запись. Игра, сборник, стилбук, геймпад, фигурка — всё в одной таблице, различаются через `typeGoodId`.

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `goodId` | `SERIAL` | `PRIMARY KEY` | автоинкремент | Уникальный идентификатор |
| `goodName` | `VARCHAR(200)` | `NOT NULL`, `UNIQUE` | — | Полное название SKU |
| `baseGameName` | `VARCHAR(150)` | | — | Базовое название игры. `NULL` для не-игровых |
| `typeGoodId` | `SMALLINT` | `NOT NULL`, `REFERENCES typeGoods(typeGoodId)` | — | Тип (`game`, `bundle`, `steelbook`) |
| `platformId` | `SMALLINT` | `REFERENCES platforms(platformId)` | — | Платформа |
| `relatedGameId` | `INTEGER` | `REFERENCES goods(goodId)` | — | Для аксессуаров — ссылка на игру |
| `publisherId` | `SMALLINT` | `REFERENCES publishers(publisherId)` | — | Издатель |
| `regionId` | `SMALLINT` | `REFERENCES regions(regionId)` | — | Регион выпуска |
| `editionId` | `SMALLINT` | `REFERENCES editionTypes(editionId)`, `DEFAULT 1` | `1` (Standard) | Тип издания |
| `firstReleaseYear` | `SMALLINT` | `CHECK (BETWEEN 1950 AND 2100)` | — | Год первого релиза игры (оригинал). Может быть `NULL` |
| `firstYearEdition` | `SMALLINT` | `CHECK (BETWEEN 1950 AND 2100)` | — | Год выпуска этой версии. Может быть `NULL` |
| `remakeYear` | `SMALLINT` | `CHECK (BETWEEN 1950 AND 2100)` | — | Год ремейка (если ремейк) |
| `audience` | `SMALLINT` | `CHECK (IN (0,6,12,16,18))` | — | Возрастной рейтинг. Может быть `NULL` |
| `ageRestricted` | `BOOLEAN` | `NOT NULL` | `FALSE` | Запрещён к продаже до 18 |
| `dataQuality` | `VARCHAR(10)` | `NOT NULL`, `CHECK (IN ('full','partial','minimal'))` | `'minimal'` | Качество данных |
| `barcode` | `VARCHAR(50)` | `UNIQUE` | — | Штрихкод (опц.) |
| `sku` | `VARCHAR(50)` | `UNIQUE` | — | Внутренний артикул (опц.) |
| `notes` | `TEXT` | | — | Заметки. Опционально |
| `isActive` | `BOOLEAN` | `NOT NULL` | `TRUE` | Признак «активен» |
| `createdAt` | `TIMESTAMP` | `NOT NULL` | `NOW()` | Когда создан |
| `updatedAt` | `TIMESTAMP` | | — | Когда изменён |

**Индексы:** PK, `UNIQUE (goodName)`, `UNIQUE (barcode)`, `UNIQUE (sku)`, `INDEX (baseGameName)`, `INDEX (platformId)`, `INDEX (typeGoodId)`, `INDEX (relatedGameId)`, `INDEX (isActive)`.

**Бизнес-правила:**
- **Сборник = `typeGoodId = 'bundle'`.** Флаг `isBundle` не используется.
- `editionId DEFAULT 1` (Standard). Запись с `editionId = 1` — первая в `editionTypes`.
- `firstReleaseYear`, `firstYearEdition`, `audience` — могут быть `NULL`.
- `firstReleaseYear` (оригинал) и `firstYearEdition` (эта версия) — **разные** события. Пример: NFS Underground (2003) → Limited Run (2005). Позволяет видеть «волны популярности».
- `remakeYear` — только для ремейков.
- Для игр (`typeGoodId = 'game'`) обязательны: `platformId`, `regionId`, `editionId`, `firstReleaseYear`, `firstYearEdition`, `audience` (проверка в приложении).
- При создании товара приложение автоматически привязывает English в `productLanguages`.

### 2.2. `productGenres` — Жанры товара (M2M)

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `productId` | `INTEGER` | `NOT NULL`, `REFERENCES goods(goodId) ON DELETE CASCADE` | — | Товар |
| `genreId` | `SMALLINT` | `NOT NULL`, `REFERENCES genres(genreId) ON DELETE RESTRICT` | — | Жанр |
| `createdAt` | `TIMESTAMP` | `NOT NULL` | `NOW()` | Когда привязан |

**Индексы:** `PRIMARY KEY (productId, genreId)`, `INDEX (genreId)`.

**Бизнес-правила:** для игр и сборников — минимум 1 жанр (заполняет кладовщик). Для не-игровых — записей нет.

### 2.3. `productLanguages` — Языки товара (M2M)

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `productId` | `INTEGER` | `NOT NULL`, `REFERENCES goods(goodId) ON DELETE CASCADE` | — | Товар |
| `languageId` | `SMALLINT` | `NOT NULL`, `REFERENCES languages(languageId) ON DELETE RESTRICT` | — | Язык |
| `createdAt` | `TIMESTAMP` | `NOT NULL` | `NOW()` | Когда привязан |

**Индексы:** `PRIMARY KEY (productId, languageId)`, `INDEX (languageId)`.

**Бизнес-правила:**
- **При создании товара приложение автоматически привязывает English.** Кладовщик может добавить другие языки или удалить English.
- В M2M нельзя `DEFAULT` на `languageId` — автопривязка на уровне приложения.
- Для игр — минимум 1 язык.

### 2.4. `bundleItems` — Состав сборника (M2M)

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `bundleGoodId` | `INTEGER` | `NOT NULL`, `REFERENCES goods(goodId) ON DELETE CASCADE` | — | Сборник (`typeGoodId = 'bundle'`) |
| `includedGoodId` | `INTEGER` | `NOT NULL`, `REFERENCES goods(goodId) ON DELETE RESTRICT` | — | Игра в сборнике |
| `quantity` | `SMALLINT` | `NOT NULL`, `CHECK (quantity > 0)` | `1` | Количество экземпляров |
| `createdAt` | `TIMESTAMP` | `NOT NULL` | `NOW()` | Когда привязан |

**Индексы:** `PRIMARY KEY (bundleGoodId, includedGoodId)`, `INDEX (includedGoodId)`.

**Бизнес-правила:**
- `bundleGoodId != includedGoodId`.
- `bundleGoodId` должен иметь `typeGoodId = 'bundle'`.
- **MVP: таблица есть, наполнение не обязательно.** Достаточно `typeGoodId = 'bundle'`. Наполнение — фаза 2.

**Ориентир для наполнения:** Trine Ultimate Collection, The Banner Saga Trilogy, No More Heroes 1+2, Cat Quest 1+2, Hotline Miami Collection, Bayonetta & Vanquish, The Escapists 1+2, Commandos 2 & 3, Disney Classic Games, Tales of Vesperia + Berseria + Zestiria, Zombies Ate My Neighbors + Ghoul Patrol, Bloodrayne 1+2, Axiom Verge 1+2, Samurai Shodown NeoGeo Collection, Guacamelee! 1+2, Oddworld Collection.

### 2.6. `stock` — Остатки на складах

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `warehouseId` | `SMALLINT` | `NOT NULL`, `REFERENCES warehouses(warehouseId)` | — | Склад |
| `goodId` | `INTEGER` | `NOT NULL`, `REFERENCES goods(goodId) ON DELETE RESTRICT` | — | Товар |
| `quantity` | `INTEGER` | `NOT NULL`, `CHECK (quantity >= 0)` | `0` | Физическое количество (включая `countOfRepair`) |
| `countOfRepair` | `INTEGER` | `NOT NULL`, `CHECK (countOfRepair >= 0 AND countOfRepair <= quantity)` | `0` | В предпродажной подготовке |
| `avgCostRub` | `NUMERIC(12,2)` | `CHECK (avgCostRub >= 0)` | — | Средневзвешенная себестоимость RUB. `NULL` — неизвестна |
| `avgCostUsd` | `NUMERIC(12,2)` | `CHECK (avgCostUsd >= 0)` | — | Средневзвешенная себестоимость USD. `NULL` — неизвестна |
| `avgCostEur` | `NUMERIC(12,2)` | `CHECK (avgCostEur >= 0)` | — | Средневзвешенная себестоимость EUR. `NULL` — неизвестна |
| `avgCostUpdatedAt` | `DATE` | | — | Дата последнего обновления себестоимости. **`2026-09-01`** — флаг «миграционная цена вручную». Дата приёмки — рассчитана из закупки |
| `lastExchangeRateDate` | `DATE` | | — | Дата курса, по которому пересчитано (аудит) |
| `createdAt` | `TIMESTAMP` | `NOT NULL` | `NOW()` | Когда создана |
| `updatedAt` | `TIMESTAMP` | | — | Когда изменена |

**Индексы:** `PRIMARY KEY (warehouseId, goodId)`, `INDEX (goodId)`, `INDEX (quantity)`, `INDEX (countOfRepair)`.

**Вычисляемое:** `availableForSale = quantity − countOfRepair` (в запросах, не хранится).

**Бизнес-правила:**
- `avgCost* = NULL` — цена неизвестна. Не заменять 0.
- `avgCostUpdatedAt = 2026-09-01` — «ручная» цена, требует пересмотра. В интерфейсе — фильтр.
- `avgCostUpdatedAt = дата приёмки` — рассчитана из закупки.
- При приёмке: если `avgCost* IS NULL` — `avgCost = landedCost` (без усреднения). Если есть — пересчёт по формуле.
- Продажа уменьшает `quantity`, `avgCost*` не меняется.
- **Приёмка = обновление `quantity` и `avgCost*`.** Факт приёмки виден по остатку. Отдельного флага «оприходовано» нет.

### 2.7. `stockWriteOffs` — Списания со склада

**Назначение:** списание товара, не подлежащего восстановлению.

| Поле | Тип | Ограничения | По умолчанию | Описание |
|---|---|---|---|---|
| `writeOffId` | `SERIAL` | `PRIMARY KEY` | автоинкремент | ID списания |
| `goodId` | `INTEGER` | `NOT NULL`, `REFERENCES goods(goodId)` | — | Товар |
| `warehouseId` | `SMALLINT` | `NOT NULL`, `REFERENCES warehouses(warehouseId)` | — | Склад |
| `quantity` | `INTEGER` | `NOT NULL`, `CHECK (quantity > 0)` | — | Количество списанных единиц |
| `reason` | `VARCHAR(50)` | `NOT NULL`, `CHECK (IN ('defect_on_receipt','defect_on_return','lost_in_delivery','lost_in_return','other'))` | — | Причина |
| `sourceType` | `VARCHAR(20)` | `NOT NULL`, `CHECK (IN ('purchase_receipt','sales_return','sales_delivery','manual'))` | — | Источник |
| `sourceId` | `INTEGER` | | — | ID источника (purchaseOrderItemId, salesReturnId, salesOrderId) |
| `writeOffDate` | `DATE` | `NOT NULL` | — | Дата списания |
| `notes` | `TEXT` | | — | Заметки |
| `createdAt` | `TIMESTAMP` | `NOT NULL` | `NOW()` | Когда создана |
| `updatedAt` | `TIMESTAMP` | | — | Когда изменена |

**Индексы:** PK, `INDEX (goodId)`, `INDEX (writeOffDate)`, `INDEX (reason)`.

**Бизнес-правила:**
- При списании: `stock.quantity -= quantity`, `stock.countOfRepair -= quantity` (если был в подготовке). `stock.avgCost*` не меняется.
- `defect_on_receipt` — брак при приёмке закупки.
- `defect_on_return` — повреждён при возврате.
- `lost_in_delivery` / `lost_in_return` — потеря при доставке (компенсация OZON, не убыток).
