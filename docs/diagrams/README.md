## 🔍 Как читать

| Обозначение | Значение |
|---|---|
| `PK` | Первичный ключ |
| `FK` | Внешний ключ |
| `\|\|--o{` | Один-ко-многим |
| `o\|--o{` | Ноль-или-один-ко-многим |
| `nullable` | Может быть `NULL` |
