# Веб-интерфейс (FastAPI)

Здесь находится код веб-приложения: роутеры, шаблоны и статика.

## Структура
- `app.py` — точка входа (сборка FastAPI).
- `routers/` — эндпоинты (API). Разделены по ролям: `keeper/` (кладовщик), `seller/` (продавец), `settings/` (настройки), `_shared/` (общие хелперы).
- `templates/` — HTML-шаблоны (Jinja2).
- `static/` — CSS, JS, картинки.

## Запуск
Из корня проекта: `uvicorn web.app:app --reload`
