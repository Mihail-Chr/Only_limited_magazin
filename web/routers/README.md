# Роутеры (API)

Эндпоинты FastAPI. Каждая папка — отдельная зона ответственности.
Общие хелперы (работа с JSON, справочниками) лежат в `_shared/`.

- `keeper/` — инвентаризация, управление товарами.
- `seller/` — ручные продажи, заказы.
- `settings/` — справочники, загрузка данных, история.
- `api/` — вспомогательные API (курсы валют).
