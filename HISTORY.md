## 💡 Ключевые решения (чтобы не забыть)

| Решение | Почему |
|---|---|
| SQLite для локальной работы | Простота, не требует сервера, файл-база |
| PostgreSQL для production | Полная схема, 34 таблицы, надёжность |
| `cost_price_synthetic = price × 0.7` | Искусственная себестоимость, пока нет реальных закупок |
| `cost_price_at_sale` в `posting_item` | Точная маржа на момент продажи (цены менялись) |
| Компенсация остатков (`fix_initial_stock`) | Чтобы не уходить в минус после загрузки истории |
| Минимизация ПД (никнейм, город, возраст) | Снижение риска 152-ФЗ |
| Два контура (закупка / продажа) | Независимое развитие, пересечение только через `stock` |
| `HISTORY.md` как инструкция | Перед «зависающим» шагом — обновить, потом действовать |

## 2026-10-26 — Стратегическое решение: развёртывание и подготовка базы

**Решение:** переходим к этапу развёртывания на сервере, но перед этим приводим базу в порядок (чистка названий, объединение данных).

**Видение продукта (актуализировано):**
1. **Учёт** — фундамент для всего остального.
2. **Помощь Покупателю** — сравнение цен, алерты о выгодных предложениях, учёт состояния товара. Для MVP: ручной ввод закупок и отслеживание логистики.
3. **Помощь Продавцу** — управление ценами (авто/полуавто), подготовка к отправке, списание, возвраты.

**Что сделано (MVP кладовщика):**
- Инвентаризация (массовое изменение остатков).
- Добавление товара (с умными полями, чеклистом, валидацией).
- Справочники (типы, платформы, издания, издатели) с возможностью добавления.
- Пересчёт валют (RUB, USD, EUR, GBP).

**Что дальше (по приоритету):**
1. **Обновление со второго магазина OZON** (API уже получен).
2. **Чистка базы** (удаление «Видеоигра», нормализация `baseGameName`).
3. **Развёртывание на VPS** (Timeweb Cloud, тариф Low, 300 ₽/мес).
4. **Роль Продавца** (корзина цен, подготовка к отправке).
5. **Роль Покупателя** (ввод закупок).

**Технические решения:**
- Хостинг: **Timeweb Cloud** (Россия, 300 ₽/мес).
- Браузеры: Chrome, Yandex, Safari.
- Планшет: только для Продавца (просмотр), остальные — десктоп.
- База: остаёмся на SQLite (для MVP), при росте — PostgreSQL.
