# SQL-скрипты

Скрипты для создания схемы базы данных и наполнения справочников.

## Порядок выполнения

Выполнять **строго по номерам** (есть зависимости по внешним ключам).

### Схема (DDL)

| Файл | Что создаёт | Таблиц |
|---|---|---|
| `01_schema_reference.sql` | Справочники | 15 |
| `02_schema_goods_stock.sql` | Товары и склад | 7 |
| `03_schema_purchase.sql` | Закупка | 5 |
| `04_schema_sale.sql` | Продажа | 7 |
| `05_schema_ozon_integration.sql` | Интеграция с OZON (каналы, карточки) | 2 + ALTER |

**Итого: 36 таблиц** (34 из модели + 2 для OZON).

### Справочники (DML)

| Файл | Что заполняет |
|---|---|
| `11_data_reference.sql` | Валюты, регионы, типы изданий, типы товаров, статусы, маркетплейсы, площадки закупки, службы доставки, жанры |
| `12_data_geo_game.sql` | Страны, платформы, языки, издатели |
| `14_data_rawg.sql` | Платформы, жанры, издатели (сгенерировано из RAWG API) |

### Тестовые данные

| Файл | Что создаёт |
|---|---|
| `13_data_test.sql` | Тестовый сценарий: закупка → приёмка → продажа → выплата |

### Роли (DCL)

| Файл | Что делает |
|---|---|
| `20_role_operator.sql` | Создаёт роль `operator` (кладовщик + продавец) с правами только на данные |

## Как выполнять

**Через DBeaver:**
1. Открыть файл в SQL-редакторе
2. Убедиться, что выбрана правильная база
3. `Alt + X` (Execute SQL Script)

**Через psql (командная строка):**
```bash
psql -U postgres -d only_limited_magazin -f sql/01_schema_reference.sql
```

## Заметки

- Все скрипты обёрнуты в `BEGIN; ... COMMIT;` — при ошибке откатываются целиком.
- Для повторного запуска на чистой базе — сначала `DROP DATABASE`, потом `CREATE DATABASE`.
- При изменении схемы — обновить соответствующий файл и добавить запись в раздел «История» внизу файла.
